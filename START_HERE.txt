Donggeurami Editor v2.7.3 - Windows Start Guide

FIRST RUN
1. Extract the ZIP completely.
2. Double-click INSTALL_AND_RUN.bat.
3. Keep the black Command Prompt window open.
4. The browser will automatically open http://127.0.0.1:5500.

AFTER THE FIRST RUN
- Double-click RUN_DONGLE.bat.

IMPORTANT
- Do NOT double-click app.py. It is the server source file and may open in VS Code.
- Do NOT run the program from inside the ZIP preview. Extract it first.
- If Windows SmartScreen appears, choose More info > Run anyway only if you trust this file.
